# The Dressing Room × Shresth

Ready-built static presentation. No installation, build, database or environment variables.

Import this folder as a Vercel project. Framework: Other. Build command: leave empty. Output directory: `.`. The included vercel.json sets these values.

Open the deployed homepage. Click Start the show; use Space or Right Arrow to advance and Left Arrow to go back. The final runway screen stays visible. Presenter notes are optional.
